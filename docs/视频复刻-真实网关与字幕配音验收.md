## 3. 真实网关多主体验收

### 3.1 执行前要求

- 使用获得授权的原视频、人物肖像及产品图片；测试账号素材台账有效。
- 明确网关、模型、协议、费用上限和是否启用额外付费的自动质检修复。
- 原片解析、分镜、素材组与主参考图均可追溯。
- 测试期间保留解析凭证版本、任务 ID、逐段检查点及脱敏用量记录。

故障注入仅在隔离测试环境执行，不对生产网络、存储权限或真实用户任务做破坏性操作。

### 3.3 判定规则

- 逐镜头对照原片、素材组和成片，记录目标出现区间与替换结果。
- 目标错换、身份互换、未授权事实、漏换均判失败；HTTP 成功和任务 success 不能替代画面检查。
- QC unknown 或采样覆盖不足标记待人工确认，不算全量通过。
- 修复后必须复检目标段两侧边界，保留成功后缀不意味着接缝天然一致。
- 任务失败后的退款、用量、失败报告与保留产物需一致。

### 4.2 执行方式

1. 保存最终确认文案、实际配音音轨、字幕文件与成片的脱敏副本。
2. 用 ffprobe 检查帧率、尺寸、音频采样率与时长；用 ffmpeg 完整解码检查。
3. 将字幕逐句与音频波形及人工听辨结果对照；ASR 只能作为辅助，不能自行证明语义正确。
4. 在每段开始、结束及整片末尾抽查，同时完整播放至少一次；长视频不能只抽首尾。
5. 对照原片口播窗口和镜头边界，记录实际偏差及修复后结果。

建议验收阈值（正式执行前由负责人确认）：

- 句级字幕相对实际发声的起止偏差不超过 200ms；词级字幕不超过 150ms。
- 片尾相对目标时间轴偏差不超过 200ms，不接受随段数增长的持续漂移。
- 漏字、重字、句尾截断、产品事实错配为零容忍项。
- 无字幕越界、明显遮挡主体或超出安全区域；音轨无可闻爆音、口播被持续掩盖等问题。

这些是人工验收建议，不代表当前代码已实现全部自动门禁。

### 4.3 已有自动检查的边界

- `worker/tests/test_replica_segment_recovery.py`：成功段恢复、中间低分段精确修复、真实 ffmpeg 异构媒体归一化与拼接回归已通过。

- 成片时长及解码检查只证明媒体完整性，不证明字幕语义、口型或配音时间对齐。
