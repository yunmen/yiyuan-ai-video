# 改造透镜:把参考改造成你的版本

当用户带来一条参考、并要求"做他自己的版本"(换一个人、商品、世界、表演、故事或观众)时,用这套透镜。多个改动可以同属一个创作意图。

## 先保留角色,再重塑形态

在复刻参考的"语义时间意图"到目标里:如果一个榜单头像在介绍某选手时弹出、并随评判落定,就把这些事件绑定到目标自己的脚本上。换了说话者或重写的论点会改变秒数,但那种"关系"可以保留。当某个间隔本身就是要设计的一部分时,保留明确的时钟区间。

替换一个对象前,先理解它在作品里扮演的**角色**:一个主讲人可能同时是头像、声音、B-roll 主体、手机画面,以及 MG 系统里的身份;一个商品可能是道具、一块屏、一次演示、一个主张,以及最后的 CTA。要**沿着这个角色在每一个真实出现处去改造**,而不是只改掉它最显眼的那几个像素。

目标不必复制一个已经不再合适的"形态"。保留一个动作 / 构图 / 呼应的**目的**,再去导出一个对新的身体、商品、平台、观众说得通的形态:一只猫可以用定住的姿态、凝视、尾巴或构图来表现自信,而不必照搬人类的手势;一个没有屏幕的商品,可以用另一种证据来演示同样的收益。

## 可用的改造透镜(用于思考,不是要填的字段)

- **主体或身份**:谁承担叙事角色,以及这个身份出现的每一处;
- **商品或品牌**:商品真相、用途、道具、UI、Logo、配色、证据、卖点、CTA;
- **脚本 / 语言 / CTA**:含义、口播节奏、屏上措辞、演示,以及跟随新台词的时序关系;
- **平台 / 时长 / 画幅**:哪些故事功能保留、压缩、展开或需要新构图;
- **视觉或调性**:跨生成镜头、字幕、排版、MG、特效、音效的整体美术方向,且不抹掉参考里有用的结构;
- **增删一个系统**:把原系统承担的活重新分配,而不是留下叙事空洞;
- **多参考**:说清每个功能来自哪条参考,在创意方案里解决冲突,而不是把所有表面细节都混在一起。

## 两个常见范式

- **"用我的脸拍同款"**:原片是足球榜单、笑话围绕球员。把用户带进镜头,带上参考那种调侃的自信、好用的构图、给榜单留出的空间;保留完整口播 Craft,像导任何主演一样导这个人的魅力与气场。原片照片只确立外观,不决定声音与演绎——声音方向决定选角,视频方向决定何时用源片段去约束新镜头。
- **"用我的商品"**:原片是播客推荐一瓶商品,用户想推自己的 App。那句"你指望我一个个敲?"可以引出手机扫小票的演示,主机手持手机、覆盖镜头展示 App 在用、图形揭示同一刻的理解。脚本、动作、画面、CTA 都从产品真实能提供什么长出来。当人和商品一起变时,把二者的关系一起考虑:为什么这个人推荐它、搭档怎么回应、什么让这次相遇好看。

## 把生成当普通制作

把图像模型想成见多识广的画师,视频模型想成见多识广的摄像组与演员,音频生成想成见多识广的声音团队。"真实"是一种美术方向(手机质感、自然光、纪录片式运动、环境音),不是对素材来源的声明。正常任务就是去**创造目标素材**。

外部参考在"公共世界知识无法确定精确身份"时必不可少:用户本人、冷门私有商品、专有界面、精确 Logo 或数据展示。一次被接受的生成图 / 镜头 / 声音,随后可以成为后续工作的权威。

- **参考条件生成**:当身份、美术方向、构图或商品连续性重要时使用,输入引导镜头,而不必作为字面的首帧或尾帧出现;
- **关键帧约束生成**:当端点图本身就是要设计的连续变化的一部分时使用;
- **纯文本生成**:当镜头受益于变化、且不需要精确视觉锚点时使用。

## 保持媒体依赖浅而有用

直接生成真正要用的素材:主 A-roll 画面、反打、一段 B-roll、商品特写,或一个组件槽位。第一个被接受的主讲人图往往已经是主 A-roll 画面;另一个 A-roll 视角可以由它派生——描述新的镜头关系、视线、重复出现的物体、光线,以及镜头转过去时自然发生的变化。独立的身份资产或地点图,只在作品本身独立需要它时才值得生成。避免一串只为了喂下一次生成而存在的中间图。
