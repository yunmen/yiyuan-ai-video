# 视频方向:用参考素材驱动生成

复刻一条表演 / 动作 / 镜头主导的片子时,决定是否让"源素材"去约束新的镜头。三种控制语义:

- **参考条件生成(reference-conditioned)**:当身份、美术方向、构图或商品连续性重要时使用。输入(原片片段 / 用户参考图)引导新镜头,而不必作为字面的首帧或尾帧出现。适合"换脸不换运镜""换商品不换构图"。
- **关键帧约束生成(keyframe-constrained)**:当端点图本身就是要设计的连续变化的一部分时使用(如一个物体从 A 形变成 B 形)。端点图是设计契约。
- **纯文本生成(text-only)**:当镜头受益于变化、且不需要精确视觉锚点时使用。留给模型发挥,适合环境空镜、过渡。

## 让素材承载"随时间展开"的行为

当预期的改造依赖一个"随时间发生"的表演 / 物理 / 镜头关系时,保留一段有用的源片段作为时间行为证据,让素材把这种行为带入新的生成请求。例如:一段连续的舞蹈、一个固定镜头拍到的意外、一段运镜跟随,这些是"关系"而非"某一帧像素",可以直接作为条件喂给生成。

## 复刻时的取舍

- 表演主导(A-roll):优先让被接受的表演决定时间,画面可改变尺寸/位置/可见性/同框,但语义时间锚点保留。
- 动作 / 镜头主导:用源片段约束动作节奏与摄像机运动,再替换其中的主体(人/商品)。
- 避免为了"看起来像原片"而把原片主体写回画面;被替换维度的具体外观应交由替换流程/参考图决定(见 replicate_generated_dependencies)。
