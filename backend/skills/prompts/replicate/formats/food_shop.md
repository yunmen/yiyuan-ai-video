# 复刻形态:美食探店

## 适用
餐饮门店的种草与引流:以探店视角带观众"进店",用门店环境氛围 + 招牌菜品特写 +
试吃反应来说服观众到店。火锅、烧烤、家常菜、咖啡、烘焙等餐饮品类通用。

## 复刻时保留的结构
- 探店动线:进店 → 门头/环境 → 招牌菜品 → 试吃 → 到店引导(CTA),节奏跟随原片。
- 菜品呈现:特写机位(上桌 / 夹取 / 冒烟 / 拉丝 / 流心等)与试吃反应(表情、点评)
  落在原片的同一时间位置。
- 声音质感:老板/店员介绍与现场环境音(锅气、翻烤、切配)保留探店的真实感。

## 替换维度注意
- 换菜品:新菜品出现在原片同一位置与时机(上桌 / 特写 / 试吃),外观交给用户上传的菜品图。
- 换门店/环境:用户上传的门店照片决定环境外观;门头、灯光、桌椅保持原片同一镜头语言。
- 换出镜人:保留"边逛边讲"的探店关系与机位,只换外观/声音。
- 换话术:新台词的人气卖点(招牌 / 必点 / 排队 / 团购)与到店引导落在原时间位置。
