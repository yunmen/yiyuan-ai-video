# 复刻形态:主讲人讲解(presenter-led-explainer)

## 适用
主讲人边演示边讲,常配屏幕 / 产品 / 白板;教程、功能介绍、方案讲解。

## 复刻时保留的结构
- 讲-演交替:什么时候讲、什么时候切到演示画面、两者如何呼应。
- 分屏 / 互补视角:主讲人与被演示内容的相对位置与大小关系。
- 揭示节奏:一个理解点用什么画面/图形在哪一刻揭示。

## 替换维度注意
- 换人:保留"主讲人 + 演示"的关系与机位,声音可换。
- 换产品/App:演示内容换成用户真实产品,揭示点位置不变(见 replicate_image_direction)。
- 换话术:讲解的逻辑顺序与揭示点时间对齐,不要打乱"问题-演示-理解"的链路。
