# 复刻形态:榜单 / 盘点(ranking-listicle)

## 适用
"Top N""盘点""排行"类;逐条揭示、带排名与强调。

## 复刻时保留的结构
- 揭示顺序:第几条先出、排名何时落定、强调点落在哪。
- 图形系统:排名卡 / 头像 / 中心标签的出现、弹入、停留、随下一跳退出(见 replicate_reference_understanding 的 MG 系统)。
- 字幕:条目文案与排名强调的样式。

## 替换维度注意
- 换主体(球员/商品/人物):保留"排名揭示 + 中心标签"的关系,只换外观与文案(见 replicate_transformation_lenses 的"榜单头像随介绍弹出")。
- 换数量:条数变化要重排揭示节奏,但每次揭示的"弹入-停留-退出"行为一致。
- 换话术:新台词的节奏对齐原揭示点,排名卡位置不变。
