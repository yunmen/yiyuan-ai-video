# 复刻形态:口播(talking-head)

## 适用
单人面对镜头、以"我"的口吻讲解 / 推荐 / 观点输出;知识、测评、种草常用。

## 复刻时保留的结构
- 直接对镜头(DA)的表演关系与机位(近景 / 中景、平视或微俯)。
- 语速与停顿节奏:哪个点是钩子、哪个点抛主张、哪个点收 CTA。
- 画面留白与字幕位置(通常底部居中,强调处着色)。

## 替换维度注意
- 换人:保留"对镜头说话"的关系与机位,只换外观/声音。
- 换商品:商品出现在原片的同一位置与时机(手持 / 桌面 / 屏幕),外观交给用户素材(见 replicate_generated_dependencies)。
- 换话术:新脚本的钩子与 CTA 落在原时间位置,不要拉长或压缩节奏。
