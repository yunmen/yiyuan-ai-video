# 参考视频理解方法论(视频复刻专用)

读一条参考视频时,目标是产出"时间码级的语义解读":这条片子的每个镜头在传达什么、它用哪些具体的视听选择把这种传达做出来。这套理解是后续"逐镜头逆推"与"改造"的地基。

## 从整体到细节地读

1. 先看完整条参考片:钩子、论点/故事、注意力转移、收尾与预期观众反应;把台词按时间读一遍。
2. 判断谁在承担表演、画面贡献了什么、哪些字幕 / MG / 排版 / 特效 / 音效系统**持续出现或反复出现**。
3. 对每一个被设计出来的元素,说明它的内容外观、空间关系、入场、动作、持续与退场,并把它对应到它所服务的台词、停顿或动作上。
4. 追问"这个选择对观众做了什么":建立人物、对比两个说法、累加证据、放大反应、让一个流程变清晰,还是把注意力交给下一个想法。

意义指导细看,细看又反过来加深意义。一个运动要看作路径、缩放/透明度变化、节奏、过冲与落定,以及它与相邻事件的关系。把"整体印象"和"逐帧证据"互相修正,直到两者一致。

## 让时间可见

- 对有台词的参考,先做转写并显式传入语言(中文 `--language zh`、英文 `en`),用词的起止时间把"论点"和"切镜 / 图示 / 强调"对齐。
- 用取帧与网格取证:抽关键帧、按时间间隔排成带字幕时间标签的网格;需要看运动时用逐帧抽取,用 `--transcript` 把词和画面并排。
- 不断调整查看的区间、采样间隔与单元格大小:区间拉宽看论点或持久系统,区间收窄看一次入场 / 变化 / 交接;放大单帧读排版或空间细节。
- 几张代表性静帧无法代替"时间账户":要沿台词和视觉系统,把它们的入场、变化、持续与退场都记下来。

## 保留可承接的账户

把理解写进工程文件,随着工作推进更新:

- 整体解读(ANALYSIS):这条片想达成什么、故事与节奏怎么走、每个视觉或声音系统贡献了什么、哪些系统持续或反复出现、相距很远的时刻如何关联。
- 时间码实现(TIMELINE):按"源时间 + 有意义的阶段"分段,把每个活跃对象及其细节行为,连接到它所服务的台词或动作;保留源时间码,便于复刻时精确定位。

始终区分"画面/声音里看到听到的"与"推断它意味着什么"。两处读法冲突时,重新打开相关源区间,让有争议细节清晰可辨。

## 转成新的方向

源时间码定位证据。用户诉求决定这些关系该怎样活在新的片子里:换了人 / 商品 / 话术,可能改变论点、文案、例子数量、图形内容、位置与时长。用"改造透镜"(见 replicate_transformation_lenses)来想清这次适配,并用"生成依赖"(见 replicate_generated_dependencies)决定哪些生成资产依赖哪些参考。

当预期的改造依赖一个"随时间展开"的表演 / 物理 / 镜头关系时,保留一段有用的源片段作为时间行为证据,让素材把这种行为带入新的生成请求。
