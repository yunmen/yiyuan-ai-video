# 字幕:阅读节奏与样式

复刻一条片子的"观感"时,字幕是高频被忽略却极显眼的系统。原片的字幕风格(说话人处理、位置、强调、Cue 形状与动画)应作为可复刻的视觉系统被记录。

## 分组与节奏

- 按中 / 英 / 混排分别处理阅读节奏;中文按语义短语分组,而非按字符硬切。
- 字幕的出现 / 退场要跟台词时间对齐,强调处用样式而非靠长句堆叠。

## 样式与位置

- 记录原片字幕的:说话人着色、位置(底部居中 / 跟随头部)、强调方式、Cue 形状与动画。
- 复刻时,这些样式可整组沿用,只对"被替换的说话人"改着色或标识;不要无故换掉原片的字幕系统。

## 不参与画面一致性判定

字幕内容本就该被替换(对应新脚本),因此逐镜头质检(见 shot_qc)不比对字幕文字,只比对画面结构。
