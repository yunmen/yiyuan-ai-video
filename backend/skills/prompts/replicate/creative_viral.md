# 创作要求:爆款改造

## 目标

保留原片的**情节骨架与叙事逻辑**(这个故事为什么成立),但在节奏与情绪曲线上
按短视频的传播规律重做 —— 用户要的是"用原片的成功逻辑讲我的故事,并且更抓人"。

## 保留

- **故事骨架**:钩子 → 建立问题 → 展示解决 → 收束行动号召,这条逻辑链不能断;
- 原片被验证有效的**具体动作与画面证据**(演示、对比、前后结果);
- 被替换元素之外的主体与场景。

## 改造

- **前 3 秒**:把全片最强的信息(结果、反差、最强卖点)前置到第一镜,
  不要沿用原片的铺垫式开场;
- **节奏**:压缩与原片叙事无关的过渡镜头,把省下的时长给到证据镜头;
  总时长变化控制在原片的一定比例内,且不得丢掉任何必要事件;
- **情绪起伏**:把原片平淡的中段做出一次明确的对比或转折,避免观众中途划走;
- **收束**:行动号召落在原片结尾位置,措辞按用户素材重写,给出明确动作。

## 边界

- 不得为了"更炸"而编造原片与用户素材都不支持的证据、数据或承诺;
- 不得改变被替换元素之外的品牌与场景事实;
- 节奏重排是**移动**而不是删除:任何被压缩掉的叙事功能,都要在相邻镜头里补回来。
