# 图像方向:把观察到的外观转成生成指令

复刻里常要"换一张图":换商品、换人物、换场景里的某个物体。图像方向负责把参考里观察到的外观,转成连贯的造型与场景方向,并给出替换所需的选角锚点。

## 选角锚点(人 / 商品)

- **人物**:用用户提供的肖像确立外观,但不决定声音与演绎;表情、姿态、凝视、构图要服务于这一镜的意图,而非照搬原片姿势。
- **商品**:用用户提供的商品图 / UI 确立外观;真实卖点、用途、证据由用户事实与素材决定,不要编造原片没有的功能。

## 替换时保留什么

- 保留构图、光线、主体在画面中的位置与占比、以及该元素"扮演的角色"(见 replicate_transformation_lenses 的角色视角)。
- 只把具体外观(品牌、材质、颜色、形态、身份)交给替换流程/参考图决定,不在画面描述里写回原片元素。
- 一次被接受的图常即主 A-roll 画面;反向角度、同场景 B-roll、商品特写可由它派生(见 replicate_generated_dependencies)。

## 给生成模型的措辞

- 描述"这个镜头需要这张图呈现成什么样子",而不是"这是一张图"。包含:视角、光线、与周围元素的关系、它在叙事里做什么。
- 多参考冲突时,在创意方案里说清每个功能来自哪条参考,不要混用所有表面细节。
