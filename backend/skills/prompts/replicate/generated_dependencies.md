# 生成依赖:哪些生成资产依赖哪些参考

视频复刻里,生成出来的图与视频,必须清楚"它们依据哪一份参考(原片 / 用户图 / 产品图)长出来"。关系不清,复刻就会串味:换好的脸又变回原片的人,或保留的场景被错误替换。

## 按角色建立依赖,而不是按像素

- **被替换的主体(人 / 商品)→ 依赖用户提供的图或素材**:逆推描述时,这类元素只保留"它在画面里的角色与位置",具体外观由替换流程/参考图决定,绝不在画面描述里写回原片的品牌、材质、颜色或身份。
- **要保留的场景 / 世界 / 持续道具 → 依赖原片参考**:这类元素如实、具体地描述,它们正是本次要复刻下来的部分。
- **派生镜头从权威镜头长出来**:第一个被接受的主 A-roll 画面常即主镜头;反打、同场景 B-roll、商品特写,应由它派生(描述新的镜头关系、视线、光线、重复出现的物体),而不是另起一堆互不相关的中间图。

## 保持依赖浅而有用

- 一次接受的可视权威,尽量复用到这一镜的各个部分;除非切口本身就是按字面边界帧设计的,否则不要把一镜拆成多段时各用各的权威。
- 避免长链中间图:不要为了喂下一次生成而生成一串只服务于下游的图。一个镜头要的,直接生成那一帧/那段。
- 复刻时尤其注意"人 / 商品"与"场景"的依赖边界:被替换维度依赖用户素材,保留维度依赖原片。逐镜头逆推(见 shot_reverse)与逐镜头质检(见 shot_qc)都按这个边界注入"要替换 / 要保留"。

## 与改造透镜配合

改造透镜(replicate_transformation_lenses)决定"这次换什么、保留什么";生成依赖决定"换/留的东西分别由哪份参考供给"。二者一起,才能保证复刻出来的是目标版本,而不是把原片元素又写回画面。
