# 创作要求:轻度改写

## 目标

保留原片的镜头结构与节奏骨架,但**文案与卖点表达必须重写** —— 用户要的是
"同款形式、我的内容",而不是把原片的台词原样念一遍。

把原片台词照抄进成片,在平台上表现为高度雷同,既影响推荐也容易引发版权争议。

## 保留骨架

- 镜头数量、顺序与时长:与忠实复刻一致,结构不动;
- 每个镜头的叙事功能(钩子 / 论证 / 演示 / 行动号召)与原片同位置;
- 运镜与构图照原片。

## 必须重写

- **口播措辞**:换词、换句法,不得与原片逐句重合;
- **卖点组织**:按用户素材的真实卖点重排优先级,最强的卖点前置到原片的钩子位置;
- **屏上文字与标签**:跟随新文案,不得残留原片的品类话术与原商品名称。

## 边界

- 不动结构,不做"为了新颖而增加镜头";
- 重写不等于加戏:字数与原片对应段落基本齐平,保证字幕节奏不漂移;
- 重写只作用于文案与卖点表述,不得改变被替换元素之外的画面事实。
