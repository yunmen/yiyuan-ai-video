# 个人中心常用服务

四个服务页复用《纸白影像工作室》的颜色、字体、卡片和导航，未登录时先登录，再回到所选服务。

## 功能与调用链

| 服务 | 移动页面 | 共享后端 |
| --- | --- | --- |
| 账号设置 | `pages/account-settings/index` | `account/info`、`account/update`、`account/change-password`、`account/set-password` |
| 我的素材 | `pages/materials/index` | `base/common/materials`、`base/common/materials/sync`、`base/common/upload/confirm` |
| 邀请好友 | `pages/invitation/index` | `account/invitation`、注册及首次验证码登录 |
| 消耗记录 | `pages/credit-logs/index` | `account/credits/logs` |

接口均为 POST，移动端集中 API 使用 `/v1`，由现有网关映射至后端 `/api/user/v1`。账号、素材和流水归属由用户 token 决定。

账号设置分开提交资料和密码。只修改昵称不会清空头像。用户名沿用 `account`，新增独立 `phone` 保留已绑定手机号；修改用户名或密码会撤销旧会话并重新登录。已经有密码的账号不能通过首次设置接口绕过原密码校验。头像走统一上传并验证素材归属。

上传中转成功后直接登记；H5 签名直传成功后调用确认接口，服务器核对对象存在、大小和归属再加入素材列表。列表分页支持图片和视频筛选及预览。历史已就绪台账通过迁移回填；早期直传但未确认的记录可用“找回历史素材”分批核验，每批最多 20 个，失败数量会明确显示。台账建立前没有归属记录的历史文件无法安全恢复，不根据公开地址认领他人文件。

邀请码为后端生成的稳定 8 位随机码。注册页、首次验证码登录均接受选填邀请码；老账号不能补领。新账号、邀请关系和双方奖励在同一数据库事务中提交；入账失败整体回滚，重复注册不会重复奖励。邀请码唯一性冲突通过保存点重试。

奖励由业务配置 `account.invite_reward_credits` 控制，默认双方各 **10** 永久额度，设置为 `0` 暂停奖励。页面显示服务端当前规则，实际奖励以注册时配置为准。奖励使用现有 `grant` 流水，分别说明“邀请好友注册奖励”与“填写邀请码注册奖励”。

消耗记录展示真实额度流水，筛选全部、生成扣款、失败退款和结算返还；有任务关联时可进入任务详情。本页面记录创作额度变化，不是人民币支付订单账单。

## 数据库变更

迁移文件：`backend/migrations/models/2_20261020062500_account_services.py`。

新增 `tb_user.phone`（允许空、唯一）及 `tb_user_invitation`，并从旧手机号账号回填手机号、从已有素材台账回填查询命名空间。结构通过 Aerich 0.9.1 对隔离模型前后差异生成，含 PostgreSQL、MySQL 和 SQLite 方言；未运行会连接未知业务库的自动迁移生成命令。

已有数据库需要先备份并核对当前 Aerich 版本，再在明确的目标环境执行项目升级命令。不能只发布移动端和后端代码而遗漏迁移。新建数据库由当前模型建表。

**当前未对实际环境执行升级、部署或提交推送。** 已在隔离 SQLite 内存库验证迁移、数据回填和回退。PostgreSQL/MySQL 结构及并发锁行为、真实 Redis、短信和对象存储仍需目标环境联调。回退迁移会删除邀请关系，应先备份。
