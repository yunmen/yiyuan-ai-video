# 选角与声纹（voice-casting）

## 一次选角，复用声音身份

- 用 **Voice Design**（如 `@hypit/mimo-speech`、`@hypit/fishaudio-speech`、`@hypit/elevenlabs-speech`）
  把一段约 **5 秒**自然试音转成一个可复用的 **Voice Reference**（普通音频资源）。
- 关键：一个角色**只设计一次声纹**，之后所有镜头、画外音都复用同一个 Resource。出镜表演
  与纯音频旁白是**同一声纹的两种用法**，不是两个声音身份。
- `DigitalHumanTool` 的 `voice` 当前为 TTS 音色字符串；复用同一数字人声音时，传入
  `voice_reference`（现成声纹音频地址）并与 `digital_id` 绑定，使同一数字人跨任务/跨镜头声音一致。

## 声纹描述要「压缩成一段生动指令」

- 一段短描述即可：可辨识的声音角色 + 令人愉悦的音色特质 + 特有的说话态度。
- 例：「年轻女声，清亮甜美、上扬音区、轻盈顺滑；像朋友兴奋地跟你分享一个发现，好奇让提问更灵动，
  会心的笑意给笃定的回答添暖。」—— 高音也可从容，低音也可灵动，音高与语速是不同维度。

## 表演角色与画面解耦（重要）

- **A-roll** 定义的是「这段表演在时间线上的角色」，与其视觉呈现分离：数字人可全屏、可缩成小窗、
  可被 B-roll 覆盖、甚至完全离开画面，但声音仍是同一个 Take。
- **audio-only A-roll**：当某段没有出镜表演（桌面演示、纯 MG 讲解、被 B-roll 覆盖的旁白）时，用
  **Voice Clone** + 同一声纹生成纯音频片段，画面由 Media / MG / 字幕轨道补充。
- 三个问题要分清：
  1. 此刻说话人是否出镜？（观看关系）
  2. 声音来自被覆盖的可见 A-roll，还是纯音频 A-roll？（音频归属）
  3. 该段是「出镜表演主导」还是「独立旁白主导」？（更高层表达结构）

## 口播不改写文案

- 口播需逐字念出，故 `DigitalHumanTool` **不改写 `text`/`prompt`**（与视频生成的 prompt 改写相反）；
  入参 `text`/`prompt` 直接作为台词下发。
