# 对镜头说话表演（talking-head）

## 核心思路

一个数字人口播片段 = **一张人物+场景图（形象）+ 一个可复用声纹 + 一段口播脚本**，由说话视频模型
产出「这个人真的在表演」的画面，含口型、表情、手势、眼神与自然的剪辑跳切。画面与声音由同一段表演
同时承载（出镜 A-roll）。

## 一张图承载整段表演

- 生成角色+场景图时，让人物**正面朝向镜头、无头倾斜/旋转**，留出后续可能用到的手势空间与构图留白
  （如人物略偏右，左侧留给图标/字幕）。
- 同一张 character-and-scene 图可驱动多个镜头片段，靠**自然切镜**制造「创作者剪辑感」，
  而不是一镜到底的模拟录像。
- `DigitalHumanTool` 的 `avatar` 即这张主图；`reference_image` / `pose` 用于派生姿势
  （backend `digital.Service.resolve_pose_variant` 已支持「换姿势不换人」，保持同一数字人形象）。

## 用经过验证的说话配方

- 推荐组合：**形象图 + 一个声纹 + 口播脚本 + 复用 Recipe（导演风格）+ 可选动作文本**。
- 编辑节奏用 `pause-trim-jump-cuts`：镜头可固定，表演者保持生动；小幅姿态变化让视频像真人剪辑。
- 动作要有「理由」：一个耸肩否定一个论点、一个前倾让 punchline 更个人化；让口播/字幕/图标承载
  精确数字，手只做可读的强调手势。

## 多镜头拼接

- 多段数字人表演或「数字人 + 演示/图表」组合，用 `compose` / `multiseg`（worker 既有合成能力）
  拼接成一条成片；切镜节奏由脚本 Segment 边界驱动。
