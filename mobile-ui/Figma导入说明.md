# 千溪 mobile UI · Figma 导入说明

1. 在 Figma 新建一个 Design 文件，进入画布。
2. 将本目录的「千溪-mobile-设计总览.svg」拖入画布，或逐个拖入 screens/ 下的 SVG。
3. 取消组合后可编辑文字、矩形、色彩和图标路径；按页面需要创建 Frame。
4. 中文正文使用 Microsoft YaHei、标题使用 SimSun。若 Figma 提示缺少字体，可替换为本机苹方、思源黑体与思源宋体；替换后复核换行。
5. 对照 screens/ 下的 PNG 检查导入差异，再根据设计规范建立 Auto Layout、组件变体与原型连接。

本轮未连接 Figma 账号、未创建在线文件。SVG 由已实现页面的文字与几何图层导出，未将整张截图伪装成可编辑设计稿；水墨品牌图为内嵌位图。SVG 不包含 CSS 阴影和完整 Web 交互，实际效果以页面 PNG 与本地应用预览为准。

所有账号、作品、余额、套餐价格和数字人信息仅为设计示例，不代表正式业务数据。样例只在本地截图浏览器中使用，不存在于产品页面代码中，也不调用真实支付、生成或短信接口。

mobile/UI_DESIGN.md 包含页面路径、设计令牌、交互规则与验证边界。此目录按仓库 .gitignore 规则仅保存在本地。
